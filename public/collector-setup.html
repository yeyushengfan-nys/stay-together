这是一份可检查源码的 Chrome 扩展，尚未上架商店。网站本身不能操作你的订房账号；扩展安装后，任务才会在你电脑上的 Chrome 执行。

安装前，确认访问范围

扩展在携程酒店页、同程酒店页读取可见酒店名、房型、价格、早餐和取消政策；在住一起网站接收任务并返回这些资料；接收城市、日期、人数、区域、汇总预算、必要条件和匿名偏好权重，不接收同行人姓名与完整个人偏好。它会识别平台登录页地址并暂停。

页面权限仅限本站、hotels.ctrip.com、www.ly.com、passport.ctrip.com、passport.ly.com。没有 Cookie、密码管理、浏览历史或全站访问权限。不读取登录输入框，不提交订单或付款。查价过程中平台仍会正常接收你的搜索条件。

任务存在浏览器会话内，重启整个 Chrome 后不能恢复；网站保存已收到的报价，可通过网站的数据导出功能备份。结果不会自动上传为全站共享报价。

第一步：下载并解压

下载采集助手 ZIP

解压后得到一个包含 manifest.json 的文件夹。不要选择 ZIP 文件本身，也不要上传任何密钥。

第二步：在 Chrome 加载

  1. 打开 Chrome，在地址栏输入 chrome://extensions。
  2. 开启右上角“开发者模式”，点“加载已解压的扩展程序”。
  3. 选择刚解压的文件夹，核对扩展名称“住一起 · 本机酒店采集助手”和访问范围后安装。

第三步：回网站开始

  1. 用同一个 Chrome 打开住一起，刷新页面；同行偏好属于各浏览器本地数据，换浏览器前先在原浏览器导出备份，再在 Chrome 导入。
  2. 保存同行偏好，填写城市、入住退房、房间数和成人数。确认已连接0.2.7采集助手，点击“找酒店并自动比价”。首次建议上海、1间、2成人、3家候选。
  3. 点击“找酒店并自动比价”。平台标签页会自动打开，只读房型页参考价；发生登录、验证码或持续日期不符时会暂停并显示该标签页。
  4. 由你处理后回网站点“我已处理，继续采集”。你可随时取消；不会自动解验证码或换账号。

这版具体能做什么

支持上海、北京、杭州、广州、深圳、成都；1间房、1—4成人、不带儿童、最多14晚。从主平台读取最多12家已加载的非广告候选，按预算和已有偏好线索安排顺序；最多核对8家，套餐不符合时继续补位，合适套餐再按完整名称搜索另一平台。已取得的具体房型设施、开业年份和报价用于同行必要条件检查；位置、卫生等缺证据的要求会单列，不推定已满足。

携程从具体房型套餐行读取页面均价，并尝试点击一条套餐的“预订”进入订单预览核对全程房费；最终提交按钮不会点击。同程已按真实登录页面适配主房型列表。新任务默认只读房型参考价，不进入订单预览；历史核验案例另行保留。两平台只有房型、床型、早餐、取消与付款条件一致时，才显示预览总额差价。未识别到就会暂停，不会以起价或旧快照填补。

2026年10月25日已从网站发起并完成一次两平台自动采集：上海艺龙安悦酒店（浦东大道歇浦路地铁站店），10月25日至27日，1间房、2成人，自动回传携程8条、同程4条套餐。悦眠大床房、同床型、无早餐、线上预付及确认后30分钟内免费取消条件一致的两晚预览总额为：携程388元，同程370元，相差18元。同程优惠前506元、优惠136元，含当前账号白金权益；税费未单独核实。携程餐食依据保留套餐列表原文，同程餐食依据为预览页逐晚明细。全程没有手工录价、提交订单或付款。登录暂停也已验证。自动结果以每次新采集为准，单个案例不代表稳定覆盖所有酒店。

相同酒店、房型、早餐、取消和付款条件未核对一致前，价格并不代表可直接比较。返现、担保和税费另列，不以金额最小自动推荐。

停用方式：在 chrome://extensions 关闭或移除此扩展。原同行偏好不会因此被修改。页面结构或平台访问限制变化时，采集可能暂停。
