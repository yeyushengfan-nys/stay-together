# 公开源码范围

整理日期：2026-10-27。

本公开副本对应已部署 **v55**，来源提交 **`682d0260270cfa503f206234e95d7d2ddc20689c`**，含 **0.2.7** Chrome 扩展。本轮在已脱敏的 v51 公开副本上合入该提交的指定应用源码与测试，保留公开说明及已脱敏测试，不上传原工作目录、原始 Git 历史或私密材料。

新增源码包含显式参考价选择、逐人冲突归属、评价适用范围检查及仅所有者可见的失败诊断。参考价范围只改变预算检查依据，其他必要条件未知或冲突仍会阻断。两家真实酒店的正向首选／备选验收尚未通过，不能将离线正向测试写成现场使用成果。

## 包含

- 网页、浏览器扩展、服务端及构建配置源码。
- 依赖清单、锁文件、空值环境变量模板和部署配置示例。
- 离线测试及经过检查保留的历史固定材料。
- 已脱敏的项目进度、历史测试结论、运行与能力边界说明。

`PROJECT_STATUS.md` 是统一的进度入口。后续更新同一文件，不要求读取或导出完整聊天记录。

## 不包含

- 完整聊天记录、客服咨询原文、个人行程备份和未脱敏用户资料。
- `.env`、`.env.local`、`.dev.vars` 等真实运行配置，以及密钥、Cookie、登录输入、平台账号会话和连接器会话。
- 实际 `.openai/hosting.json` 部署身份；仅保留 `hosting.example.json` 占位模板。
- `public/verification-evidence/**` 原始证据文件及 `docs/full-price-*.json` 原始记录。
- `node_modules/`、构建产物、本机运行状态及 Git 历史导出。

部分历史说明中的原始证据路径因此有意不公开，链接可能无法在本仓库打开。这些内容不能被描述为读者可独立复核的公开证据；可公开检查的源码、脱敏结论与离线固定材料应分别看待。

## 统计和展示口径

历史报价带有当时日期、平台及账号条件，不能当作当前库存或价格。模拟测试、日志验证、本人反馈、外部用户验证和未来目标分开记录；没有外部试用或人工基线的数据，不写成用户增长、普遍准确率或节省时间成果。

本轮在禁止真实网络请求的条件下运行 39 个离线脚本，39 个通过。`docs/public-source-checks.json` 仅包含相对测试文件名、退出状态及汇总元数据，不收录测试输出、绝对路径、聊天、客服记录或真实用户资料。

本次仅公开源码与说明，没有发布微信小程序，也没有开放访客无限制调用模型。未新增项目级开源许可证；已有第三方文件的许可声明予以保留。
